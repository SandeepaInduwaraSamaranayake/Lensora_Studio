# 📸 Lensora Studio

**Lensora Studio** is a modern desktop application designed for **photography studios and freelance photographers** to efficiently manage, organize, and navigate large collections of photos and projects.

Built with **Java 25** and **JavaFX**, Lensora Studio provides a fast and intuitive workspace for managing complete photography workflows-from organizing client folders to handling thousands of images with ease.

---

## ✨ Features

### 📁 Project Management
- Organize photography projects in a structured workspace.
- Browse project folders using a dedicated folder tree.
- Quick breadcrumb navigation.
- Back and forward folder history.

### 🖼️ File Management
- Fast file browsing with detailed information.
- Copy, cut, paste, move, rename, and delete files.
- Drag & Drop support.
- Open files or folders directly in the system file explorer.
- Copy file or folder paths.
- Background file operations with progress tracking.

### 📷 Image & Metadata
- Display image metadata.
- View file properties.
- Support for common photography image formats.

### ⚡ Workflow Management
- Manage complete photo workflows.
- Organize client deliverables.
- Simplify project navigation.
- Efficient handling of large photo collections.

### 🎨 Modern User Interface
- Clean JavaFX interface.
- Dockable panels powered by SnapFX.
- Dark mode support.
- Responsive layout.
- Keyboard shortcuts for common operations.

## 🚀 Getting Started

### Prerequisites

- Java JDK 25
- Maven 3.9+
- Git

### Clone the Repository

```bash
git clone https://github.com/<your-username>/lensora-studio.git
cd lensora-studio
```

### Build

```bash
mvn clean package
```

### Run

```bash
mvn javafx:run
```
